## 二、软件功能概述

本软件是一套面向内容创作者的**多平台智能采集与转录管理系统**，实现从视频链接输入到结构化逐字稿输出的全自动流水线。核心能力包括：

1. **多平台统一路由**：自动识别抖音/B站/YouTube/小红书/快手/视频号等6大平台链接类型
2. **智能采集策略**：Chrome CDP直取字幕 / yt-dlp视频下载 / MediaCrawler搜索采集，按平台自动分派
3. **多引擎转录编排**：faster-whisper（GPU本地）/ Paraformer（在线API）/ 飞书妙记三种引擎，智能切换
4. **多级容错降级**：每个平台3-5级独立兜底策略，CDP超时→自动启动→视频下载+Whisper→仅音频+tiny→在线API
5. **字幕质量自动校验**：CDP提取后自动检测汉字数/中文占比/行数/话题标签，不合格立即降级到本地转录
6. **双通道输出**：结构化Markdown → Obsidian知识库 + 飞书多维表格API同步
7. **断点续传**：转录manifest逐条保存，中断后可续传
8. **GPU自动检测**：首次运行探测CUDA→缓存配置→所有脚本复用

## 四、核心创新点（用于申请表"技术特点"栏）

1. **多平台统一采集路由引擎**：基于正则匹配自动识别6大视频平台链接类型，动态分派对应采集策略（Chrome CDP浏览器注入/yt-dlp下载/MediaCrawler关键词搜索），实现"输入一条链接，输出结构化逐字稿"的一键式处理。

2. **多级智能降级容错系统**：每个平台配置3-5级独立兜底策略链，覆盖CDP连接超时、字幕质量不合格、视频下载失败、转录引擎超时等异常场景。各级策略独立超时控制，失败自动切换下一级引擎，确保任务最终完成。

3. **CDP字幕质量自动校验算法**：针对抖音Chrome CDP提取的字幕数据，自动检测中文字符数量、中文占比、行数结构和话题标签密度等维度，判定是否为真实的对话逐字稿而非视频简介，不合格时自动触发降级链路。

4. **多引擎转录智能编排**：集成faster-whisper（本地GPU加速）、Paraformer（在线API，中文专优）、飞书妙记（云服务，300分/月免费）三种转录引擎，根据平台特征和资源可用性自动选择主引擎，失败后自动切换备用引擎。

5. **断点续传与进度持久化**：转录任务的manifest在每条视频处理完成后实时写入磁盘，支持进程中断后从已完成位置继续，避免长任务重复计算。

6. **双通道结构化输出**：转录结果自动生成含YAML frontmatter的Markdown笔记写入Obsidian知识库，同时通过飞书API同步至多维表格，支持前端交互式查询和分析。

## 八、常见问题

**Q: 用了外部开源库（faster-whisper/yt-dlp/MediaCrawler）会影响申请吗？**
A: 不影响。你通过标准接口（import/subprocess）调用它们，没有把它们的源码贴进你的代码里。软著保护的是你的编排逻辑、降级链、质量校验、数据管道——这些全部是你原创的。

**Q: Python 脚本不编译成 exe 能申请吗？**
A: 可以。软著保护的是源代码本身，文本形式的 .py 和 .js 完全符合要求。

**Q: 需要提供可执行程序吗？**
A: 不需要。只需要源代码文档 + 说明书 + 申请表。

**Q: 代码里有数据目录（collections/ downloads/）要提交吗？**
A: 不需要。只提交源代码 .py 和 .js 文件，数据文件和 .gitignore 排除的内容不提交。
